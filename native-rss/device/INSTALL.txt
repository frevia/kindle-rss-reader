RSS Reader 安装说明

v0.0.4 beta 已发布兼容代码、自动同步、文章与选区翻译和在线升级。
普通兼容试装可直接通过 USB 安装 beta.2；验证 beta.1 → beta.2 在线升级时先装 beta.1。
正式版最新版入口不包含 beta，具体下载地址见本文末尾。

Kindle 兼容版按屏幕和触摸能力检查设备；已有真机记录为 KPW3，新增机型仍待实机验收。
要求 ARMv7、可识别的 Kindle 5／Upstart 系统、8 位灰度竖屏和受支持的触摸输入。
范围与诊断见 native-rss/docs/COMPATIBILITY.md。
请先完成所用越狱教程中的后续环境设置，并在 Kindle 设置中关闭设备密码锁。

安装
1. 在电脑解压名称以 -Kindle.zip 结尾的兼容安装包。
2. 用能传文件的 USB 数据线连接 Kindle。
3. 把 native-rss、documents、extensions 三个文件夹合并复制到 Kindle 磁盘，
   放在打开磁盘后能直接看到 documents 的这一层，不要多套一层解压文件夹。
   不要先删除原有文件夹。选择“合并”，不要替换整个文件夹；
   没有合并选项时，打开同名文件夹，分别复制里面的内容，保留原有书籍和插件。
4. 在电脑安全弹出 Kindle，再拔掉数据线。其他机型先打开 RSS设备诊断，
   或 KUAL → Kindle RSS → 导出 RSS 诊断报告；按兼容说明检查后再启动。
5. 从已有的入口打开：
   书库里的 RSS Reader，或 KUAL → Kindle RSS → RSS Reader。选择一种方式即可。

本应用通过复制文件安装，不用点“更新 Kindle”。
入口没出现或点开后马上退出时，再看本包 native-rss/docs/TROUBLESHOOTING.md。
不同越狱环境附带的工具可能不同，排查页保留了检查和补装步骤。

首次阅读
连接 Wi-Fi，点“添加订阅”，填入网站提供的 RSS / Atom 订阅地址并保存。
返回文章列表后 beta 默认在后台自动同步，也可点左下角“菜单 → 同步”手动下载。
等下载完成后打开一篇文章。
网站首页地址不一定是订阅地址。下载完成后可以离线阅读文字和图片。
日常操作、批量导入和备份见本包 native-rss/docs/USAGE.md。

退出、备份与升级
1. 在文章列表点左下角“菜单 → 退出”，确认回到 Kindle 系统书库，再连接电脑。
2. 把整个 native-rss 文件夹复制到电脑备份，再用最新版合并覆盖程序文件。
3. 保留 native-rss/data，订阅、收藏和阅读记录都在里面，删除后会丢失本地数据。
   安装包不带这个文件夹；不要用整个文件夹替换的方式覆盖它。
4. 安全弹出并拔线，再次打开检查原有数据。能正常使用时，无需重装启动工具。

beta 还可通过“菜单 → 设置 → 在线升级”检查后续 beta 与正式版。
验证本次在线升级时，先 USB 安装 beta.1，再检查并下载 beta.2，校验后安装重启。
升级前备份、停用已启用的首页适配，并保留至少 400 MB 空间；安装期间不要接 USB 或关机。
真实断电恢复尚未验收。完整步骤见 native-rss/docs/INSTALL.md。
备份可能包含 data/translation.conf 中的 API Key 和 .update 中的回滚数据库，不要公开上传。

可选首页 RSS
首页 RSS 默认关闭。支持的固件可在应用设置开启，首次正常退出后自动安装；其他机型或固件的开关为灰色。
支持范围和启停方法见 native-rss/docs/HOME.md。
已经启用时，升级、卸载或更新 Kindle 固件前先在 KUAL 中选择“停用首页 RSS”。

卸载
先停用已启用的首页 RSS。退出并备份后，删除 native-rss、extensions 里的 native-rss，
以及 documents 里的 RSS阅读器.sh 和 RSS设备诊断.sh。
只删除本应用的文件，不要删除整个 documents 或 extensions，也不要删除其他应用的共享工具。

连接电脑后，在 documents 里找到 RSS-device-report.txt。
成功和失败均可按 native-rss/docs/COMPATIBILITY.md 中的模板反馈。
