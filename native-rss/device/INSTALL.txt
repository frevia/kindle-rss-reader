RSS Reader — KPW3 开发版安装说明

完整安装教程（含升级、订阅导入和排查）：
https://github.com/frevia/kindle-rss-reader/blob/main/native-rss/docs/INSTALL.md
本包也包含 native-rss/docs/INSTALL.md，可离线阅读。

运行条件
已具备自制程序运行环境的 Kindle Paperwhite 3（KPW3），已验证固件 5.16.2.1.1。
需要 KUAL；书库启动另需配置 Scriptlets。本包不提供越狱或这些工具的安装，不依赖 KOReader。
设备需已有 /mnt/us/libkh/bin/fbink、timeout、flock 及系统 LIPC 等工具；诊断入口可辅助检查。
刚越狱完成时，先按完整教程准备 KUAL、适合 Kindle 的 FBInk 及必需工具，再复制本包。
启用设备密码锁时启动器会拒绝运行；需要保持密码锁时请暂不使用本应用。
当前为开发版本，基本图文阅读和退出恢复已有实机验证，长期使用及其他机型仍未完整验收。

首次安装
1. 下载 Release 的 KPW3 安装 ZIP；源码 ZIP 不能直接安装。不要使用“更新 Kindle”。
2. 已有安装时，先退出阅读器，将整个 native-rss 文件夹备份到电脑。
3. 解压 ZIP，将 native-rss、extensions、documents 三个目录的内容合并到 Kindle 用户盘根目录。
   根目录是直接包含 documents 的位置，即设备内的 /mnt/us。不要额外套一层解压文件夹。
   不要整体替换 documents 或 extensions，以免删除已有书籍和扩展。
4. 安全弹出 USB 用户盘，打开 KUAL，在 RSS Reader 菜单中选择 RSS Reader。
   已配置 Scriptlets 时也可从书库打开 RSS Reader（documents/RSS阅读器.sh）。

首次使用
连接 Wi-Fi，在界面添加 RSS/Atom 订阅地址并同步。
批量导入：退出后把 feeds.opml 放到 native-rss/data/feeds.opml（目录不存在时创建）；
重新启动，点击左上角 RSS Reader → 订阅 → 底部 OPML → 导入 OPML，确认后返回列表同步。
导出的订阅列表位于 native-rss/data/subscriptions.opml，仅含订阅和分组。
完整数据位于 native-rss/data/rss.sqlite；备份前退出应用，复制整个 data 目录。

升级与退出
升级前退出并备份；合并覆盖程序文件，保留 native-rss/data，切勿先删除旧目录。
退出入口：文章列表左上角 RSS Reader → 退出 → 确认“退出应用”。
运行期间暂时抑制 USB 磁盘模式，退出后恢复；休眠会结束应用，再次启动可继续阅读。
不要强杀会话启动器，也不要设置 RSS_UI_GUARD 绕过检查。

故障排查
KUAL 中选择“导出 RSS 诊断报告”；已配置 Scriptlets 时也可运行 RSS设备诊断.sh。
报告位于 documents/RSS-device-report.txt。反馈时提供版本、机型、固件和复现步骤。
报告可能含私人订阅地址和错误上下文，公开前检查脱敏，不要上传数据库或 OPML。
字体与证书位于 fonts、certs，请保留完整目录。数据库和 OPML 可能含私人订阅地址。

卸载
退出并备份 data 后，移除 native-rss、extensions/native-rss，以及 documents 下的
RSS阅读器.sh、RSS设备诊断.sh。不要删除整个 documents 或 extensions。
删除 native-rss/data 会丢失订阅、缓存和阅读记录。

校验
安装包外部的 SHA256SUMS.txt 用于校验 Release 附件；包内 MANIFEST.json 记录资源哈希，
BUILD.json 记录二进制与源码对应关系。功能以所下载的 Release 说明为准。
