Kindle RSS — KPW3 开发验证包

尚未真机验收，不是正式发布版。不要通过“更新 Kindle”安装此 ZIP。
仅面向已越狱的 KPW3、5.16.2.1.1。程序不依赖 KOReader。

待完成连接和恢复预检后，将包内 native-rss 与 extensions 合并到 Kindle USB 根目录。
先备份已有 native-rss 目录；本包不包含个人数据库、订阅文件或自动安装脚本。
KUAL 中的“RSS 阅读器（开发版）”调用 native-rss/launch.sh。
已配置 Scriptlets 的设备也可以打开 documents/RSS阅读器.sh；两种入口使用同一启动器。
启动失败或异常退出后，可在 KUAL 选择“导出 RSS 诊断报告”，或运行 RSS设备诊断.sh；
重新连接 USB 后读取 documents/RSS-device-report.txt。
启动器还要求设备已有 /mnt/us/libkh/bin/fbink，以及兼容的 timeout、flock 和 LIPC 工具。
在真机前置检查完成前，不应通过设置 RSS_UI_GUARD 绕过启动器。

中文字体、HTTPS 根证书及许可位于 fonts、certs 和 licenses。
搜索、订阅名称及分组可用原生拼音键盘，完整词组连续输入，ü 用 v；点击候选词后再确定。
数据保存在 native-rss/data/rss.sqlite。批量订阅文件放到 native-rss/data/feeds.opml，
在应用中点击“导入订阅”，然后点击“同步”。订阅地址可能含私人凭据，请保管好 OPML 和数据库。

运行时 USB 磁盘模式被暂时抑制，退出应用后恢复；充电或已配置的 USB 网络可继续使用。
休眠时会结束应用，重新启动可继续阅读。不要强杀会话启动器。
已提供独立恢复进程及内核父进程死亡保护；启动器被 SIGKILL 的恢复路径尚未真机验收。
恢复进程和启动器同时被强杀、系统进程异常或设备掉电仍可能需要重启设备。

卸载前先退出应用并备份 data，然后移除 extensions/native-rss 和 native-rss。
卸载不修改固件；删除 native-rss/data 会丢失本地文章、订阅和阅读状态。

包内 MANIFEST.json 可用于核对文件 SHA-256；BUILD.json 记录二进制与源码对应关系。
kindle-rss-source-dev.zip 提供本项目源码；依赖下载位置与 SHA-256 记录在 tools 中。
