# RSS Reader v0.0.4-beta.5

整理设置页排版，并补齐在线安装时的字体生命周期修复。本版同时包含 beta.4 的会话锁交接修复。[下载 beta.5](https://github.com/frevia/kindle-rss-reader/releases/tag/v0.0.4-beta.5)。这是预发布版本，正式版最新版仍为 v0.0.3；历史 beta 附件保持不变。

## beta.1～beta.4 用户先看这里

**推荐正常退出、备份整个 `native-rss`，再通过 USB 安装完整 beta.5 包，保留 `native-rss/data`。** 具体步骤见[安装与升级教程](INSTALL.md#通过-usb-升级)。

旧版安装流程仍由旧程序与旧启动器执行。beta.1～beta.3 可能因会话锁交接失败而回滚，beta.1～beta.4 还缺少进度字体保护；仅下载 beta.5 不能提前修复正在执行的旧启动器，直接在线安装仍可能失败。

开发验证在线升级时，先从已核对 SHA-256 的 beta.5 包取出 `native-rss/launch.sh`，正常退出后替换设备同名文件，再从原入口重新打开旧 beta，随后检查、下载并安装 beta.5。使用 SSH 时也要先退出并原子替换；不要使用只包含锁修复的 beta.4 启动器。详见[启动器迁移](INSTALL.md#旧版升级前修复启动器)及[在线升级测试](INSTALL.md#在线升级测试)。

已回滚时先确认原版本能打开，保留个人数据和 `.update` 备份，记录失败阶段并导出诊断；不要删除数据库、SQLite 日志或升级 journal 强制跳过恢复。

## 本版变化

- 设置页统一名称、右侧开关状态及下方说明，收紧留白，保留整行触摸区域。在线升级右侧显示当前版本和箭头；“关于与许可”移入独立详情页，保留许可、源码和第三方条款位置，返回仍回到设置。
- 安装前把实际使用的字体复制到已有私有会话缓存，再交给安装器显示进度，安装进程退出后才清理。避免替换 FAT 文件系统上已映射的字体时触发 SIGBUS；字体缺失或复制失败时停止安装并恢复系统。
- 保留安装后的显式解锁、文件与归档校验、数据库备份、启动确认和失败回滚。无数据库结构或升级包协议变化，订阅、收藏、正文、翻译配置和阅读位置继续保留。

升级前连接 Wi-Fi，停用已启用的首页 RSS，并保留至少 400 MB 可用空间。安装期间保持唤醒，不连接 USB、不按电源键或关机。网络超时可重试或改用 USB，不绕过校验。

## 已有验证与边界

- KPW3／5.16.2.1.1 已复现 FAT 字体映射替换后退出 135，同样操作使用 `/tmp` 副本正常。补齐两项启动器修复后，真实下载并校验原始 beta.4 云端包，完成备份、安装、自动重启及正常退出重开；9 张数据表内容与升级前基线一致，订阅和翻译配置文件一致，自动同步已恢复。
- 新设置页已通过本地 ARM 构建的真机显示、在线升级和关于入口及返回检查；订阅、文章数量与开关状态保持原样。相关界面测试覆盖开关保存、详情返回及升级流程。
- 回归测试覆盖默认和自定义字体副本、源字体被替换后副本仍可用、复制失败停止安装，以及原有锁继承、解锁失败和恢复路径。完整宿主测试、ARM 构建及归档一致性以本版发布工作流结果为准。

以上 beta.4 在线实测属于热修客户端证据，不代表未修复的旧客户端可以直接在线安装 beta.5，也不等于 beta.5 已完成跨机型验收。其他 Kindle 机型、真实断电恢复、反复休眠和长期使用仍待验证，范围见[兼容说明](COMPATIBILITY.md)。首页适配仍仅限已核对哈希的 KPW3／5.16.2.1.1。
