# RSS Reader v0.0.3（待发布）

整理日期：2026-10-30。面向 Kindle Paperwhite 3；相对于 v0.0.2，重点更新阅读界面、原生首页订阅卡片及异常恢复。

## 发布状态

源码与 KUAL 版本号已更新为 0.0.3。当前只准备 Release 草稿，没有公开安装附件；公开最新版仍为 v0.0.2。

当前程序链接 CREngine。固定上游声明为 GPL version 2，现有组件包含 Apache-2.0 代码和数据；仓库尚未确认组合许可及完整对应源码的分发方案。安装清单仍为 `public_release_ready=false`，发布工具会拒绝生成公开附件。详情见[第三方组件说明](../../THIRD_PARTY_NOTICES.md)。这一版本号不表示该检查已完成。

## 新增

- 网页正文可单篇后台下载，也可按订阅自动下载以后的新文章，支持取消、继续和失败重试。RSS 原文与网页正文分别保存阅读位置。
- 新版正文排版保留标题、引用、代码和图文结构；保留原排版、独立阅读位置及失败回退。
- 正文支持左滑下一页、右滑上一页，保留点击翻页。末页滑动不会自动跳到下一篇；竖向拖动、多指和按钮区域拖动不会误触翻页。
- 可选的 Kindle 原生首页适配将原有 Kindle+ 推荐卡位替换成最多三张订阅书卡。卡片内显示来源、未读优先的文章标题、正文摘录、日期和未读数，点击打开对应文章。阅读器设置中可控制显示。

## 界面与性能

- 文章列表把范围标题、分组选择、未读／全部／收藏和搜索集中到上方；左下角放菜单，右下角放上下页按钮。列表行收紧留白，短标题时可一页显示七篇。
- 同步改为弹窗，可后台运行、取消、重试失败项目及进入缓存管理。
- 统一各页状态栏字号、顶部间距、返回按钮和阅读面板样式，保留各页时间及返回按钮的位置；收紧阅读正文与顶栏间距。
- 原生首页书卡按实际标题高度分配摘录空间，调整标题箭头对齐与分隔线样式。
- 缓存常用图标，避免同步时重复写入未变化的图片缓存，减少绘制与存储开销。

## 修复

- 打开文章时，将已读状态、阅读位置、正文来源及最近文章一起保存。任一步写入失败会整体回滚，错误返回文章列表；返回时保存进度失败也能离开正文，避免存储已满时反复进入错误页。
- 修复重启后私有目录权限变化导致的启动失败。
- 补齐首页后台的 USB 存储恢复任务，检查实际进程而非只依赖旧健康记录。自动恢复不主动切换前台应用；手动启用、停用保留打开首页的行为。
- 清理本组件重载首页产生的诊断报告，避免它们持续出现在书库或占用系统状态分区。
- 修复部分大尺寸 PNG 缓存失败，并保留下载失败时的 RSS 原文和阅读记录。

## 升级与数据

升级前正常退出阅读器，备份整个 `native-rss`，合并复制安装文件并保留 `native-rss/data/`。网页正文使用新增附表，保留订阅、收藏和旧阅读位置；不要用旧备份覆盖当前数据库。

首页卡片是需要单独安装的开发功能，仅验证 KPW3 固件 5.16.2.1.1 的匹配原文件。普通安装包不带设备固件补丁，应用里的显示开关不会自动安装适配。已安装旧适配时，更新后执行一次 `home.sh enable` 补装恢复任务；更新 Kindle 固件或卸载前先停用适配。详见[首页适配指南](HOME.md)。

## 验证与限制

- 本轮功能代码通过全部 27 个 CTest 测试目标，ARM 静态构建通过。
- KPW3 真机验证两种排版下的六组写入故障回滚，以及正常打开文章、翻页、返回列表与退出。故障通过数据库触发器模拟，并非再次填满设备存储。
- 真机验证首页恢复时保留商店前台，返回系统首页后重新显示订阅书卡；个人数据库前后校验值一致。
- 本轮未完成整机重启、物理 USB 拔插及微信读书等各类前台应用的完整回归；长期休眠、耗电与其他机型仍未充分验证。上述结果针对本地开发构建，不能替代将来的发布附件验收。
- 网页正文仅尝试提取公开、无需登录的 UTF-8 / ASCII 静态 HTML；不执行脚本，不支持付费墙、旧编码网页或多页拼接。
