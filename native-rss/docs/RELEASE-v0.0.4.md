# RSS Reader v0.0.4

在 Kindle 上发现订阅源、自动同步，并在离线阅读时查看已缓存的译文。这一版还加入了 GitHub 在线升级。

- **发现订阅源。** 从 OPML 源库按主题查找并添加订阅，下载源库后可以离线查找。
- **自动同步。** 默认开启。打开阅读器及使用期间按 30 分钟间隔检查，离线时等待 Wi-Fi，不唤醒休眠设备。
- **文章与选区翻译。** 支持英文转简体中文、原文／译文／双语切换和离线缓存。需配置自己的翻译服务及 API Key，主动翻译时会向该服务发送所选内容，服务可能计费。
- **在线升级。** 手动检查并下载后续正式版，校验安装包、备份阅读数据并自动重启。包含 beta.6 的书库入口重启修复。
- **可选首页 RSS。** 支持的设备可在设置开启，首次正常退出后自动安装适配。默认关闭。

操作详见[使用指南](USAGE.md)。

## 设备范围

正式版面向 Kindle Paperwhite 3（KPW3，2015 款）。其他符合条件的 ARMv7 Kindle 可按[兼容说明](COMPATIBILITY.md)试用。首页 RSS 仅适用于原首页文件通过 SHA-256 校验的 KPW3／5.16.2.1.1，具体启停见[首页指南](HOME.md)。

## 安装与升级

安装附件为 `RSS-Reader-v0.0.4-Kindle.zip`。v0.0.3 及 beta.1～beta.5 用户建议通过 USB 升级。退出后备份整个 `native-rss`，合并复制安装包，保留 `native-rss/data`。

如果上一次在线安装中断，先从原入口重新打开，确认回滚完成，再退出、备份和复制。此前启用过首页 RSS 时，先完整停用适配。详见[安装与升级指南](INSTALL.md#通过-usb-升级)。

## 验证范围

在 KPW3／5.16.2.1.1 上验证了从 v0.0.3 经 USB 升级、从 beta.6 经书库入口在线安装并自动重启，以及测试目录中的程序和数据库回滚。在线验收使用本地测试更新源和实际候选 ZIP。订阅、收藏和阅读位置得到保留，正文翻页、长按、休眠与唤醒通过真机检查。

KUAL 入口的完整在线升级、安装中真实断电恢复和其他机型仍待验证。从 KUAL 使用阅读器时，可按上方 USB 步骤升级。首页首次启用的历史记录见 [beta.6 说明](RELEASE-v0.0.4-beta.6.md)。
