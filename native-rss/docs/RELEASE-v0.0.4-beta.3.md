# RSS Reader v0.0.4-beta.3

Kindle 兼容测试版的第三次 beta 构建，先生成 Release 草稿，尚未公开。草稿不会出现在在线升级中；公开下载仍为 [beta.2](https://github.com/frevia/kindle-rss-reader/releases/tag/v0.0.4-beta.2)。本版保留此前的自动同步、翻译与 Kindle 兼容功能，新增订阅源发现并改善升级反馈。

## 本版变化

- **订阅管理任务首页**：菜单 → 订阅集中提供我的订阅、发现订阅、订阅源库、管理分组和导入与导出。列表底部仅保留翻页，表单在右上角保存，左上角返回放弃草稿。
- **OPML 订阅源发现**：内置中文独立博客与 Awesome RSSHub Routes 源库，支持刷新、离线查找、真实主题筛选和逐项添加。可添加自己的 HTTP(S) OPML 文件地址，要求以 `.opml` 结尾且不带查询参数或片段，下载后仍验证内容。源库与个人订阅分别保存，失败或取消保留旧缓存，移除源库不删除已添加的订阅。
- **升级进度反馈**：点击「安装并重启」立即显示后台数据库备份，退出阅读器后继续显示程序备份、安装与已用时间。安装期间禁用重复操作，备份失败停止安装；检查与慢速下载约每两秒反馈进度，保留原有文件校验和回滚保护。
- 修复规范化地址重复添加订阅、超大 OPML 取消不及时，并统一「订阅源库／源库」命名。

完整操作见[使用指南](USAGE.md)，历次变化见[更新记录](../../CHANGELOG.md)。无数据库 schema 迁移；旧版自定义源库记录仍可读取和移除，编辑保存时需符合新的 OPML 地址要求。源库下载、文章同步、翻译和升级共用一个后台任务。

## 安装与测试

直接测试本版可使用 `RSS-Reader-v0.0.4-beta.3-Kindle.zip`，按[安装教程](INSTALL.md)通过 USB 合并复制，保留 `native-rss/data`。升级前退出阅读器并备份整个 `native-rss`；其他机型先按[兼容测试流程](COMPATIBILITY.md#测试安装流程)导出只读诊断，首页适配范围仍仅限 KPW3／5.16.2.1.1。

待 beta.3 公开后，beta.1／beta.2 可在设置中检查并升级到本版。按[在线升级测试](INSTALL.md#在线升级测试)核对新版本、订阅、收藏、阅读位置及翻译配置。连接 Wi-Fi、停用已启用的首页 RSS，并保留至少 400 MB 空间；安装期间不要连接 USB 或关机。

**从 beta.1／beta.2 升级到本版时，安装流程仍由旧版执行。** 新的即时进度页在安装 beta.3 后才生效，需后续更高版本才能完整验收；本次升级不会提前获得新版界面，也不会把 beta.3 当作同版本更新重复安装。

本版新增源库刷新、原生触摸导航与安装进度仍待 Kindle 真机验收，真实断电恢复及其他机型也未完成验证。宿主测试、ARM 构建及归档校验由[构建工作流](../../.github/workflows/release.yml)执行，实际结果以对应运行记录为准；历史验证记录不代替本版真机验收。
