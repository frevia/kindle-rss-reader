# Kindle 原生 RSS 阅读器实施与验收

这份文档是开发任务与验收记录。只想安装或使用阅读器，请看[安装教程](INSTALL.md)与[使用指南](USAGE.md)。

目标：KPW3 独立原生应用，不依赖 KOReader 或浏览器；界面简洁，优先离线阅读和可靠恢复。

工作区原有微信读书文件处于删除状态。仅新增 native-rss，不恢复、提交或覆盖用户变更。

## 交付范围

- C++17 原生程序，libcurl 联网、libxml2 RSS/Atom/OPML、SQLite 离线存储、FreeType 中文渲染。
- 未读、全部、今日、收藏、订阅分组导航；标题搜索；稳定列表分页与返回定位。
- OPML 导入导出及重复合并，手动添加订阅，单源失败隔离，后台同步可取消。
- 本文分页、字号/行距/页边距、阅读位置、已读/收藏、图片缓存与缺失状态。
- KUAL / Scriptlets 启动、设备识别、输入、墨水屏刷新、退出/异常恢复。
- 1072×1448 灰度本机渲染、自动化核心测试、ARM 构建、KPW3 真机验证。

## 行为约束

初次无数据提供导入/添加入口；本地打开不等待网络。正文成功打开后标已读，位置独立保存。
当前列表不因后台同步自动重排；返回保留原位置。收藏不自动清除。失败不清空旧缓存。
XML 不加载外部实体，网络验证 TLS，内容大小和超时有上限。Feed URL 仅接受 HTTP(S)。
通用网页全文提取尚未定入首版；摘要不能冒充完整全文。跨端服务与多机型不在首版实施范围。

## 模块与职责

- src/feed.cpp、tests/feed_test.cpp：订阅/OPML 解析与 HTML 正文转换（Luna）。
- src/store.cpp、tests/store_test.cpp：事务存储与状态保护（Luna）。
- src/render.*、src/app.*、src/net.*、设备层、构建、文档：主线程实施与集成。
- 主线程独立审阅并修复全部结果，复跑测试，检查真实渲染图。

## 验证矩阵

解析：RSS/Atom、中文、命名空间、CDATA、空/坏 XML、外部实体、嵌套 OPML、导出转义。
存储：重复导入、同步保留状态、失败回滚、查询过滤、删除/清理保护收藏与进度、关闭重开。
UI：空态、长中文标题、多页正文、字号变更位置、返回定位、边缘触点。
网络：200/304、重定向、超时、取消、超大内容、单源失败继续更新。
设备：识别实际固件/屏幕/触摸；启动退出、休眠唤醒、USB、异常退出、长时间翻页。

2026-10-23：ARM 静态程序已部署至 KPW3 5.16.2.1.1。中文显示、搜索拼音触摸、正常退出、单次休眠和两种强杀恢复已有真机证据；原文图文分页已部署并由 ARM 程序渲染验证。尚未完成下列全部验收，不能宣称整体交付完成；详细证据见 DEVICE.md。
