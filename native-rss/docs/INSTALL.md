# RSS Reader 安装说明

把阅读器复制到 Kindle，添加订阅后，就能下载博客和新闻并离线阅读。

## 开始之前

- **机型**：已有真机记录的是 KPW3。当前源码的兼容版按能力检查其他 ARMv7 Kindle，要求可识别的 Kindle 5／Upstart 系统、8 位灰度竖屏及受支持的触摸输入；其他机型仍待实机验收，先看[兼容范围与检查方法](COMPATIBILITY.md)。历史 KPW3 专用包不适用于其他机型。
- **设备环境**：已经越狱，并完成所用越狱教程中的后续环境设置，可以从 KUAL 或书库打开第三方应用。不同越狱环境附带的工具可能不同，启动有问题时见[启动问题排查](TROUBLESHOOTING.md)。
- **设备设置**：在 Kindle 设置中关闭设备密码锁；阅读器目前不能在开启密码锁时运行。
- **准备物品**：一台电脑和一根能传文件的 USB 数据线；首次下载文章时需要 Wi-Fi。

## 其他机型测试安装

非 KPW3 设备请先阅读[兼容范围与测试安装流程](COMPATIBILITY.md#哪些设备可以参与测试)，按“备份 → 确认兼容包 → 复制文件 → 只读诊断 → 首次启动 → 分项测试”的顺序操作。兼容代码已包含在 [v0.0.4-beta.6](https://github.com/frevia/kindle-rss-reader/releases/tag/v0.0.4-beta.6) 的 `-Kindle.zip` 安装包中，无需自行构建，不要用历史 `-KPW3.zip` 试装。

测试普通阅读器即可，不要在其他机型启用首页 RSS。成功或失败都可按[兼容反馈模板](COMPATIBILITY.md#怎么反馈兼容情况)，通过 GitHub Issues 或邮件反馈机型、固件、安装包、逐项结果及脱敏诊断报告；未测项目明确写“未测试”。

## 安装

### 1. 下载并解压

先按用途选择下载页面，再展开 **Assets（下载文件）**：

| 用途 | 下载页面与安装包 |
| --- | --- |
| 兼容测试版 | [v0.0.4-beta.6](https://github.com/frevia/kindle-rss-reader/releases/tag/v0.0.4-beta.6)，下载 `RSS-Reader-v0.0.4-beta.6-Kindle.zip`。 |
| 开发验证旧 beta 的在线升级 | 先完成[旧版启动器修复](#旧版升级前修复启动器)，重新打开阅读器后按[升级测试步骤](#在线升级测试)操作。 |
| 使用正式版 | 从[正式版最新版](https://github.com/frevia/kindle-rss-reader/releases/latest)下载对应版本。v0.0.4 使用 `RSS-Reader-v0.0.4-Kindle.zip`。 |

beta 已公开为预发布版本，但不会出现在 `/releases/latest`。其他机型只使用 `-Kindle.zip` 兼容包；历史 `-KPW3.zip` 仍只适用于 KPW3，不要改名后试装。

解压后，可以看到 **`native-rss`、`documents`、`extensions`** 三个文件夹。名字里带 `source` 或 `Source code` 的是源码，不能用来安装。

### 2. 连接 Kindle，复制文件

用 USB 数据线把 Kindle 连到电脑，把这三个文件夹**合并复制到 Kindle 磁盘的根目录**，也就是打开磁盘后能直接看到 `documents` 的那一层。

不要先删除原来的文件夹。遇到同名文件夹请选择“合并”；如果电脑只提供“替换整个文件夹”，请取消，再打开同名文件夹，分别复制里面的内容，保留原有书籍和插件。升级时还要保留 `native-rss/data`。

### 文件要放成这样

```text
Kindle 磁盘
├── native-rss/          阅读器程序和资源
├── documents/          原有书籍和随包提供的书库入口
│   ├── RSS阅读器.sh
│   └── RSS设备诊断.sh
└── extensions/          原有插件和随包提供的 KUAL 入口
    └── native-rss/
```

不要多套一层解压文件夹，也不要只把 ZIP 放进 Kindle。RSS Reader 用复制文件的方式安装，不用点“更新 Kindle”。

### 3. 打开阅读器

在电脑上安全弹出 Kindle，再拔掉数据线，按设备已有的方式打开：

- **从书库打开**：在书库中找到 **RSS Reader**，点开进入阅读器。
- **从 KUAL 打开**：点 **KUAL → Kindle RSS → RSS Reader**。

选择一种方式即可。入口没出现或点开后马上退出时，查看[启动问题排查](TROUBLESHOOTING.md)。

### 4. 下载第一批文章

给 Kindle 连上 Wi-Fi，点 **添加订阅**，填入网站提供的 RSS / Atom 订阅地址，点 **保存更改**。返回文章列表，点左下角 **菜单 → 同步**，等下载完成后打开一篇文章。

现在可以断开 Wi-Fi，继续阅读已经下载的文字和图片。网站首页地址不一定能用作订阅地址，详细操作见[添加第一个订阅](USAGE.md#添加第一个订阅)。

## 可选首页 RSS

可选首页适配可将原生首页的 Kindle+ 推荐卡片替换为本地 RSS 摘要。含内置配方的安装包可在支持的 Kindle 上从设置开启，正常退出后自动安装。功能默认关闭。固件范围与启停方式见[首页适配说明](HOME.md)。

## 退出与备份

在当前开发版的文章列表点左下角 **菜单 → 退出**，确认回到 Kindle 系统书库，再连接电脑传文件。v0.0.2 的入口为 **RSS Reader → 退出**。

订阅、收藏和阅读记录保存在 `native-rss/data`。需要备份时，先退出阅读器，再把整个 `native-rss` 文件夹复制到电脑。beta 的译文缓存也随数据库保存；备份还可能包含 `data/translation.conf` 中的翻译 API Key 和 `.update` 中的回滚数据库，请妥善保管，不要公开上传。

## 升级

### 旧版升级前修复启动器

beta.1～beta.3 的旧启动器有会话锁交接问题，beta.1～beta.4 还可能在替换安装进度页所用字体时崩溃。beta.5 修复了这两项问题。beta.6 进一步修复书库入口在安装后切回 Kindle 首页、导致启动脚本被系统终止的问题。自动重启由当前运行的启动器负责，下载目标包后仍需先按下方步骤替换旧启动器。

v0.0.3 和 beta.1～beta.5 用户建议[通过 USB 升级](#通过-usb-升级)。如果上一轮在线安装中断，先从原入口打开并确认恢复完成。

开发测试旧版在线升级时，先从本地构建、已核对 SHA-256 的 beta.6 安装包取出 `native-rss/launch.sh`，在阅读器正常退出后通过 USB 替换同名文件；使用 SSH 时也应先退出并原子替换。保留其他程序和个人数据，重新从原入口打开旧 beta，再执行检查、下载与安装。重新启动后，本轮在线安装才会使用新版启动器。

已经回滚时，先确认原版能打开并导出诊断；保留 `.update` 中的备份，不要删除数据库或升级日志来强行跳过恢复。

### 在线升级

从 **菜单 → 设置 → 在线升级** 检查当前通道的新版本。v0.0.4 正式版只检查后续正式版。beta 同时检查后续 beta 和正式版，按版本号选择更新。v0.0.3 和 beta.1～beta.5 用户建议通过 USB 升级。

1. 连上 Wi-Fi，保留至少 **400 MB** 可用空间；启用过首页 RSS 时，先在 KUAL 中停用。
2. 点「检查更新」，查看版本与更新说明；有新版时点「下载更新」。下载期间可以取消，当前程序不变。
3. 下载与校验成功后点「安装并重启」。阅读器先备份数据库并退出，再替换程序与资源，完成后重新打开。安装期间保持设备唤醒，请勿连接 USB、按电源键或关闭电源。

安装包仍来自本仓库的 GitHub Releases，无需 GitHub 账号或令牌。兼容版只选择 `-Kindle.zip` 安装包并校验其 Kindle 元数据，不回退到旧的 KPW3 专用包。历史专用开发版需先通过 USB 安装一次兼容版。网络不可用、空间不足或校验失败时保留当前版本，可以稍后重试。

支持在线升级的正式版只接受版本号更大的正式版；beta 版还会检查本仓库最近 100 条发布中的后续 beta，并按版本号选择。两者都不安装草稿、主分支提交或同版本开发包。已直接安装当前公开的最新 beta 时，没有比它更新的版本会显示当前已是最新版本，这不表示检查失败。

升级保留订阅、收藏、正文缓存、翻译配置和阅读位置。未完成的文件安装会在下次从原入口启动时先恢复；新程序首次成功显示界面之前失败，也会在下次启动时恢复旧文件与升级前数据库。备份保存在 `native-rss/.update`，其中的数据库属于个人数据，不要公开上传。KPW3 已复现锁和字体问题，并验证热修后的在线安装、自动重启与数据保留；书库重启故障及验证范围见 [beta.6 说明](RELEASE-v0.0.4-beta.6.md)。真实断电恢复仍待真机验证，首次尝试前请按下方步骤做电脑备份。

### 在线升级测试

以下用于开发验收。使用 beta.6 作为测试起点时，直接从待验证的入口打开。更旧的 beta 须先按上方步骤替换启动器。GitHub 在线检查只会看到已公开、符合当前通道的版本，草稿包可用于 USB 验收。

1. 退出阅读器并备份整个 `native-rss`。其他机型先完成[只读诊断与基础测试](COMPATIBILITY.md#测试安装流程)。
2. 记录现有订阅数、收藏和一篇文章的位置；有翻译配置时只确认文件存在，不要把密钥贴到反馈里。
3. 重新打开使用 beta.6 启动器的旧 beta，连上 Wi-Fi、停用已启用的首页适配，确保至少 400 MB 空间，在 **菜单 → 设置 → 在线升级** 检查，核对找到的目标版本与本次测试版本一致。
4. 下载并校验成功后点 **安装并重启**，保持设备唤醒，期间不要接 USB 或按电源键。重新打开后，设置页应显示目标版本，订阅、收藏、位置及翻译配置仍保留。
5. 正常退出再打开，确认没有回滚提示；导出诊断，按[兼容反馈模板](COMPATIBILITY.md#怎么反馈兼容情况)补充各阶段结果及脱敏报告。失败时记录提示，不通过断电或反复覆盖文件尝试恢复。

下载遇到 GitHub 连接超时时，原版与数据应保留；可稍后重试，或改用 USB 安装完整兼容包。不要关闭校验来绕过下载失败。

### 通过 USB 升级

如果上一次在线安装中断或重启后没有看到新版，先从原入口重新打开阅读器，让它完成恢复。在设置中确认版本和阅读记录后正常退出，再通过 USB 覆盖。直接覆盖会保留旧升级记录，首次启动时仍会恢复旧程序。若原版打不开，先保留备份和升级记录，并按[回滚排查步骤](TROUBLESHOOTING.md)处理。

如果启用过首页 RSS，先在 KUAL → Kindle RSS 选择“停用首页 RSS”。更新 Kindle 固件前也先停用。

1. 退出阅读器并连接电脑，先把整个 `native-rss` 文件夹复制到电脑备份。
2. 下载最新版，按“安装”步骤合并覆盖文件，**保留 `native-rss/data`**。安装包不带这个文件夹，不要删除它，也不要用整个文件夹替换的方式覆盖它。
3. 安全弹出并拔线，再次打开 RSS Reader。在设置中核对版本，并确认原有订阅、收藏和阅读记录还在。

已经能正常使用时，升级阅读器无需重装设备上的启动工具。

## 卸载

如果启用过首页 RSS，先选择“停用首页 RSS”，确认已恢复后再删除程序。

1. 正常退出阅读器；如果还想保留阅读数据，先把整个 `native-rss` 文件夹备份到电脑。
2. 删除 Kindle 上的 `native-rss`、`extensions` 里的 `native-rss`，以及 `documents` 里的 `RSS阅读器.sh` 和 `RSS设备诊断.sh`。

只删除本应用的文件，不要删除整个 `documents` 或 `extensions`，也不要删除其他应用的启动文件或共享工具。**删除 `native-rss/data` 会丢失本地阅读数据。**

## 打不开或用不了怎么办

| 遇到的情况 | 先这样做 |
|---|---|
| 书库或 KUAL 里没有阅读器 | 按[启动问题排查](TROUBLESHOOTING.md)检查对应入口。 |
| 点开后马上退出 | 检查设备密码锁和文件位置，再按[启动问题排查](TROUBLESHOOTING.md#点开后马上退出)检查设备环境。 |
| 打开后没有文章 | 先添加订阅并同步；以前的文章可以在“全部”中查看。 |
| 下载失败 | 检查 Wi-Fi，以及填入的是否是网站提供的订阅地址。 |
| 图片没有显示 | 先重新同步。部分图片格式、特别大的图片或网站限制可能导致图片无法下载，不影响已经下载的文字。 |
| 电脑看不到 Kindle 磁盘 | 先从阅读器里退出，再重新连接，并确认数据线能传文件。 |

### 日志反馈

1. 在书库打开 **RSS设备诊断**，或在 **KUAL → Kindle RSS** 中选择 **导出 RSS 诊断报告**。
2. 连接电脑，在 `documents` 中找到 **`RSS-device-report.txt`**。
3. 到[问题反馈页面](https://github.com/frevia/kindle-rss-reader/issues)提交问题，说明设备型号、安装包文件名、故障时间，以及做了什么操作、看到了什么。系统版本能找到时也请一并提供。

其他机型试装后，即使没有遇到问题，也欢迎按[兼容反馈模板](COMPATIBILITY.md#怎么反馈兼容情况)提交结果；首次诊断和试用后诊断请在电脑分开保存，设备上的同名报告会被下次导出覆盖。

公开发送前先检查报告，遮住私人订阅地址等内容，不要上传整个 `data` 文件夹或完整订阅列表。拿不准时，可先邮件联系 [freviax@gmail.com](mailto:freviax@gmail.com)。
