# RSS Reader 界面方向

目标：KPW3 原生、简洁、清楚、稳定。优先打磨阅读与选择文章，不增加信息流功能。

## 参考案例

- Reeder Classic：https://www.reeder.app/classic/ 。参考其文章列表的内容层级与简洁阅读视图，保留本项目的未读、收藏和分组逻辑。
- Readwise Reader：https://readwise.io/read 。参考阅读与管理操作的区分。
- Readwise 墨水屏说明：https://docs.readwise.io/reader/docs/faqs/eink 。采用高对比度、无页面动画的原则。

上述是设计参考，不引入依赖、第三方服务或插件。

## 第一轮已实现

- 顶部品牌统一为 RSS Reader；页面标题 48 px，文章标题 36 px，来源日期 24 px。
- 列表左右留白 64 px，标题先于来源日期，长标题最多三行，行高与列表分页一致。
- 白底、深色文字；次要文字维持可读对比度；分隔线减少视觉噪声。
- 导航图标和文字左对齐；当前视图使用细竖线及勾选，搜索结果不误标为未读视图。
- 订阅和分组行统一图标、名称、分隔线；管理动作与订阅名称分列。
- 阅读页保留原有正文及图文分页，页脚细线表达阅读页数进度。
- 阅读设置区分收藏/已读操作与排版调节，字号、行距、页边距显示可操作边框。
- 所有原触摸区域保留，已有阅读位置及字号数据不迁移。

## 后续美化顺序

1. 依据实屏反馈调整列表密度、图标尺寸和文字对比度。
2. 统一订阅管理、空状态、错误提示和确认界面。
3. 整理搜索键盘、候选词和输入反馈。

## 本轮验证

宿主机 app/render 测试通过；列表、导航、阅读设置使用应用自身渲染器生成预览并检查。安装后仍需观察真实墨水屏残影及物理触摸。

## 第二轮：订阅管理与输入

- 订阅管理按名称、地址、分组、同步状态分区；长标题、地址和错误信息限制在各自区域内，避免挤压操作按钮。
- 搜索与编辑共用 64 px 页边距、44 px 页标题和 24 px 辅助文字。
- 输入框显示末尾五行及静态光标，长地址编辑时能看到新输入的内容。
- 字母键增加细边框，拼音候选增加分隔线；确定按钮使用黑底白字。
- 保留原有键位、候选词触摸区、删除和中英文切换逻辑。
- 管理/取消订阅确认及拼音输入回归检查通过；检查了管理、keji 候选和长地址预览。
