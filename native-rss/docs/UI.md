# RSS Reader 界面方向

这份文档记录界面设计和历次调整，供维护代码时回查。想知道按钮怎么用，请看[使用指南](USAGE.md)。

## 列表总页数（2026-10-26）

文章列表首次显示即给出准确的「当前页 / 总页数」，不再以省略号代替总页数。按当前标题、元信息行高和可用正文空间计算全部页边界，后续翻页复用结果，切换范围时复用标题及元信息的测量行数；标题、来源或宽度变化会更新测量缓存，缓存最多保留10,000篇文章。切换范围、筛选、搜索、刷新数据或同步提示显隐时重新计算。空列表和单页列表均显示「第 1 / 1 页」。

## 大图与 AVIF 缓存（2026-10-26）

- 图片解码保持最终灰度缓存不超过944×1130；大尺寸有损WebP使用libwebp解码内缩放，避免创建原尺寸RGBA缓冲，保留比例与白底透明度合成。
- 新增libavif / decoder-only libaom / libyuv，支持实际订阅中的3000×2000、10位YUV444 AVIF；先缩放YUV，再分配小RGBA。单线程、单图8MP和最大边长16384的约束在解码前生效。无损WebP及JPEG/PNG限制8MP，STB分配预算32MiB；有损WebP限制64MP，所有输入继续限制8MiB。
- 当前失败的7张WebP（最大4640×6960）和1张AVIF已在独立Kindle解码进程中逐张验证，进程地址空间上限192MiB；WebP耗时0.9–2.3秒、峰值3.6–6.2MiB，AVIF耗时约10.5秒、峰值约111MiB。缓存成功后沿用既有正文和图片面板读取灰度数据，不修改阅读状态。

## 编辑地址复用空历史订阅（2026-10-26）

修改订阅地址时，目标若被已取消且没有文章的历史订阅占用，在同一事务中回收空历史行并更新当前订阅。当前订阅ID和文章/图片状态保持不变；URL变化仍清除同步校验信息。目标仍在使用时提示地址已被其他订阅使用；已取消但保留收藏的记录不自动合并，提示通过添加订阅恢复原订阅。任何失败回滚完整事务，避免保存失败却提前释放历史地址。

## 订阅名称与键盘调整（2026-10-26）

- 订阅名称选填。新增时只需填写有效地址；同步成功后沿用 RSS / Atom 中的博客名称，尚未获取时以地址显示，自定义名称继续保留。
- 编辑时可清空名称；同时清除条件请求头，使下次同步重新读取名称。同地址清空名称不重置同步时间或文章状态。同步正在进行时须先取消，再清空已有名称，避免进行中的旧请求覆盖缓存校验信息。
- 输入页取消移至右上角；输入框显示末尾四行，中文拼音、候选词及候选翻页独立排列。字母键高104px，横向居中错位排列；清拼音/大小写与删除位于第三行两侧，底行固定为符号、空格/选首词、输入语言、确定。按键、候选词和触摸区域一起更新，外边距32px。
- 地址输入固定英文，名称、分组和搜索默认中文拼音；每次新开输入页从字母键面开始。未上屏拼音仍需先选词；取消输入或放弃表单不写库。

目标：KPW3 原生、简洁、清楚、稳定。优先打磨阅读与选择文章，不增加信息流功能。

## 全局留白调整（2026-10-26）

- 主内容、列表、订阅、表单、同步、缓存、搜索输入和确认页统一采用32px左右边距；空状态的符号、标题、说明及按钮也以32px对齐，保留既有结构。
- 分组下拉弹层扩展为完整内容宽度（KPW3上1008px），两侧各32px。菜单行、选中标记、查找和翻页的触摸区域随布局同步调整，关闭仍不穿透点击。
- 正文默认边距32px；排版面板提供32/64/78/96四档，原有自定义值保留，不迁移字号、行距或阅读位置。连续切换边距仍使用同一个文字/图片锚点，32px设置可在重开后恢复。
- 图片面板常规预览1008×440、展开1040×542；保持等比完整显示。键盘输入框和候选区扩宽，字母键随可用宽度分配，原有按键顺序及输入逻辑保留。
- 后文为历史设计及实施记录，当前横向边距以本节为准。

## OpenDesign 方案的原生承接

设计基准为 1072×1448 的 KPW3 灰度屏。NetNewsWire 的标题层级、Inoreader 的订阅分组、Folo 的导航分区用于组织阅读任务；用户设备上的 Kindle 原生微信读书用于检查墨水屏工具栏的密度与分组，不复制其书架标签或翻页胶囊。

- 列表顶部放可展开「订阅 / 退出」的品牌入口和同步图标；标题下提供分组范围、未读、全部、收藏及搜索。底部仅保留左对齐上一页、居中页码和右对齐下一页。
- 文章标题优先，来源、分组与日期退居第二层；未读实心点和收藏实心星标共用标题左侧状态列。列表行按内容高度分页，最小176px；标题只在超过整页容量时省略，元信息最多两行。
- 订阅页展示分组树和来源，来源名称与右侧编辑分别响应触摸。管理分组和 OPML 从底部进入；缓存管理归属同步页。
- 正文保留显式翻页和阅读进度，底部使用一行104px翻页栏，进度细线在上、单行页码居中，不显示百分比。正文中部轻点展开「排版、图片、信息」，替换并隐藏翻页底栏；末页仍在原位置提供「下一篇」。收藏移至顶栏，已读状态放入信息面板。
- 搜索与编辑复用离线拼音键盘；字母与数字/符号分面显示，为候选与按键保留独立区域。
- 沿用随包提供的中文字库，不以 macOS 宋体作为设备依赖。字级、行距和留白承接原型，字形仍由真实 FreeType 字库决定。

原型中的演示行为不替换现有业务：保留进入文章自动标为已读、按 UTF-8 字节及图片锚点保存位置、同步取消和现有确认保护。今日更新与继续阅读的数据接口保留，本轮导航不展示独立入口。用户已经保存的字号、行距和页边距继续生效，不做数据迁移。列表首次显示计算全部页边界以给出准确总页数，后续翻页复用分页结果；文章正文仍在打开时加载。

验证使用虚构内存数据及独立示例数据库，不读取个人订阅库；设备安装和发布单独进行。宿主渲染不能代替实屏残影、触摸校准和长期使用验收。

### 分组与导航方案原生实施（2026-10-26）

- 承接 OpenDesign v8：品牌菜单只含订阅和退出，菜单外点击仅关闭菜单；退出单独确认。首页不再显示「我的阅读」，阅读完成空状态保持撤回后的旧设计。
- 普通首页不预留空的范围说明行，筛选栏与列表上移44px；有分组或搜索说明时保留该行，分页容量与触摸区同步调整。
- 首页分组筛选使用锚定在筛选栏下方、左右各32px留白的下拉弹层，白底细边框，无阴影、动画和灰色遮罩；保留文章列表背景，每行88px、每页最多6组，多页时翻页按钮固定位置。选中项打勾，选择后立即筛选并关闭；点击外部或返回只关闭，禁止穿透触发文章、同步或翻页。查找/清除及无匹配反馈均在弹层中呈现；输入查找词复用原生键盘，提交或取消返回弹层。订阅编辑的分组选择和文章搜索键盘的范围选择继续沿用原页面。
- 首页可直接选择分组及检索完整分组路径；未读、全部、收藏与搜索共享当前范围。文章搜索有显式退出和空查询退出；切换搜索范围保留尚未提交的关键词、拼音与键盘状态。
- 订阅树支持折叠、按实际行高分页、来源阅读和独立编辑。名称、地址和分组均作为草稿，保存时一并校验；取消不写库。从同步失败项进入编辑后返回同步页，重试只请求仍失败的订阅。
- 新增 `feed_groups(path)` 表保存空分组，不重写原订阅与文章字段。分组重命名和删除在事务内完成，使用 `/` 边界匹配；兼容旧库由来源路径推导的父分组。删除只把来源移到未分组，保留所有文章状态。重命名拒绝重复名称、移入自身与子路径超长。
- 多级分组可在管理列表点「子分组」直接创建；新增和编辑表单均可选择「上级分组」，选择「顶层（无上级）」可移回根目录。选择器支持按完整路径查找和分页，排除自身及后代；选择只改草稿，保存才移动整个子树，取消不写库。移动同步更新当前及返回首页的阅读范围和折叠路径，保留空分组、订阅、文章状态与图片缓存。重名和超长路径由存储事务拒绝，不合并或覆盖已有分组。
- OPML 导入按 URL 合并，导出保留嵌套空分组。同步任务与可见页面分离，离开页面后完成/取消仍更新任务状态；失败来源分页显示。缓存页展示本地、收藏及可清理篇数，清理仍需确认。
- 正文空状态按已确认的 v8 原型还原：32px左边距、上下细线符号区、48px标题、30px说明及54px行距、96px描边按钮；按实际说明高度整体排布，超长搜索说明截断显示并保留可见修改按钮。标题、筛选栏及翻页栏保持既有布局。
- 阅读面板、正文分页高度、收藏、既有排版偏好与锚点保留。设计实施阶段仅完成本地验证；后续设备部署见 DEVICE.md 的同日记录。

## 阅读工具原生实施（2026-10-24）

- 首页顶栏只保留品牌和单环同步图标，删除本地阅读、同步文字和排序说明。文章列表的已收藏状态只用实心五角星，与来源、日期元信息行对齐。
- 四角操作和列表内容以32px边距靠边对齐，正文保留已保存的边距设置；底栏左右分别左/右对齐，保留至少88px触摸区域。
- 点击正文横向中间一半区域开关工具，整页图片也遵守这一规则。左/右侧继续翻页；图片侧区可进入对应图片面板。工具展开后点击上方可见正文先整体收起，不同时翻页。
- 三项工具互斥：再次点击当前项仅收起面板，工具栏保留；关闭全部工具恢复翻页栏。硬件/桌面方向键不会翻动排版和信息面板后方的正文。返回键依次关闭面板、工具栏、文章，顶栏返回直接回列表。
- 面板使用不透明白底覆盖，无动画、阴影或暗遮罩。开关工具不改变分页高度、阅读页和存储位置；文字按完整行遮挡，图片保留可见上半部分。
- 排版面板420px，字号24–48、每次2px；行距选项使用间距16/24/32（默认34px字号对应行高50/58/66），页边距32/64/78/96。原有自定义偏好保留，不迁移数据；连续调整使用同一文字/图片锚点，避免每次取新页首导致位置漂移。
- 图片面板662px，1008×440预览区域；放大态764px，1040×542预览区域。图片等比完整显示；预览允许小图放大，正文内图片保留原缩放规则。上一张、页数、放大/还原、下一张分开排列；支持无图、未缓存和加载失败反馈。
- 信息面板520px，包含完整标题、来源、日期、作者、原文地址和已读切换。长信息分页，前后翻页不影响正文，短末页也可返回首页。
- 阅读顺序仍使用进入文章时的列表快照；收藏、已读、排版与图片查看不刷新列表或改变下一篇范围。继续阅读、今日更新、订阅管理、OPML、缓存确认及退出入口保留。
