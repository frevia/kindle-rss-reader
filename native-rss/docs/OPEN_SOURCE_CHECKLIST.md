- [ ] **提交并推送审核后的变更。** GitHub 自动生成的源码归档只取对应提交，不包含尚未提交的许可证。仓库切换 public 需要维护者明确执行，本次没有改变可见性。
- [ ] **重新编译并发布带许可的新开发版。** 本次不处理 `v0.0.1`，以新版本的对应提交、ARM 构建、测试和安装附件为准。记录已知限制、实机验证范围和保留数据的升级方式；安装 ZIP 与源码 ZIP 都带 MIT 及第三方许可，生成附件校验值，并将首页下载入口及安装教程更新到新版本。
