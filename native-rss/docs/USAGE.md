# 开始阅读

还没有安装的话，先看[安装教程](INSTALL.md)。下面按第一次打开阅读器的顺序介绍。

本文对应已发布的 **v0.0.4 beta**，包括自动同步、文章与选区翻译及在线升级；[下载 beta.2](https://github.com/frevia/kindle-rss-reader/releases/tag/v0.0.4-beta.2)，变化汇总见[更新记录](../../CHANGELOG.md)。正式版仍为 v0.0.3，尚不包含这些新增功能；仍使用 v0.0.2 安装包请查看[该版本指南](https://github.com/frevia/kindle-rss-reader/blob/v0.0.2/native-rss/docs/USAGE.md)。

## 开发版订阅导航（未发布）

当前开发版采用“任务首页”：**菜单 → 订阅**先进入**订阅管理**，再选择**我的订阅、发现订阅、订阅源库、管理分组、导入与导出**。下面其余已发布 beta 的旧导航说明不适用于这一开发版。

- 添加个人订阅：**我的订阅 → 右上角添加**；订阅名称仍可留空。
- 列表底部统一只有页码、**上页／下页**。分组和 OPML 入口放在任务首页。
- 订阅、分组和源库表单统一在**右上角保存**；左上角返回放弃草稿。选择分组或输入名称后，仍需回到表单保存。
- 各功能列表左上角返回任务首页；输入、详情和选择页面返回所属页面。任务首页再次返回才回到原来的文章范围与页码。
- 导入／导出个人 OPML：**订阅管理 → 导入与导出**。取消订阅、删除分组和移除源库仍需单独确认，保留原有数据处理规则。

## 添加第一个订阅

“订阅”就是告诉阅读器：以后从哪个博客或新闻网站下载文章。

1. 给 Kindle 连上 Wi-Fi，打开 RSS Reader。
2. 没有订阅时，点页面上的 **添加订阅**。已经有订阅时，点左下角 **菜单 → 订阅 → 添加**。
3. 填入网站提供的订阅地址。通常可以在网站上找到“RSS”“Atom”或“订阅”入口，复制它提供的地址。
4. 名称可以先留空，下载成功后会自动读取网站名称。暂时不用分组也可以。
5. 点 **保存更改**，回到订阅页后，点左上角 **圆形返回图标** 回到文章列表。
6. beta 默认开启自动同步，返回文章列表后会在后台检查更新；正式版 v0.0.3 没有自动同步，需点左下角 **菜单 → 同步** 获取文章。

网站首页地址不一定是订阅地址。例如，打开的是博客首页，并不代表把这个地址填进去就能下载文章。如果网站没有提供 RSS / Atom 订阅，阅读器目前不能直接订阅它。

## 下载文章，再离线阅读

beta 默认自动同步，也可连上 Wi-Fi 后随时点左下角 **菜单 → 同步** 手动启动；正式版 v0.0.3 使用手动同步。手动同步的进度显示在弹窗中；点 **后台运行** 收起弹窗后，可以继续浏览和阅读，下载仍会继续。

- 显示 **部分内容未能下载** 时，先检查 Wi-Fi，再点 **重试失败项目**。订阅、网页正文和图片的失败分别显示，已保存的内容会保留。
- 想停止下载时，在同步弹窗点 **取消同步**。
- 等文章下载完成后，即使断开 Wi-Fi，也能阅读已下载的文字和图片。

### 自动同步

beta 默认开启自动同步：打开阅读器时检查更新，使用期间每 30 分钟自动同步；最近已有更新记录时不会重复同步，离线时等待 Wi-Fi 恢复，不唤醒休眠中的 Kindle。菜单 → 设置中可以关闭或重新开启。每次同步失败或取消后仍会等待下一个 30 分钟周期；需要立即重试时可随时手动同步。自动同步在后台进行，不弹出进度窗口；完成后刷新文章列表，阅读中的正文和位置保持不变，返回列表再显示新内容。同步会继续处理用户已允许的待下载网页正文和图片，不会自动翻译文章。此开关保存在本机。正式版 v0.0.3 尚无此开关，继续使用上方的手动同步方式。

如果网站只提供摘要，可以尝试下载原网页的正文，具体操作见下文。个别图片可能因为格式、大小或网站限制而无法下载。

## 下载网页正文

打开文章，点正文中间唤出工具栏，再点 **正文 → 下载网页正文**。下载在后台进行，可以继续阅读，也可以在这个面板点 **取消下载**。取消后，回到面板点 **继续下载网页正文**，或返回列表同步，即可继续待处理任务。

完成后，在 **正文** 面板选择 **网页正文**；选择 **RSS 原文** 可以切回网站订阅提供的内容。两份正文分别保存阅读位置，第一次切换到网页正文从开头阅读。下载完成不会突然替换正在阅读的页面；尚未开始阅读的新文章，会优先打开已下载的网页正文。

面板会区分正文已保存和图片未缓存；只有已缓存的图片才能离线显示，缺失图片可返回列表再次同步。下载失败会显示原因，RSS 原文、收藏和原有阅读位置仍会保留，可以点 **重试下载网页正文**。

想让某个网站的新文章自动下载网页正文，进入 **订阅 → 编辑 → 自动下载网页正文**，再点 **保存更改**。默认关闭；开启后只处理以后新增的文章，不会一次下载整个历史库。关闭后暂停自动任务，单篇手动下载仍然可用。此偏好保存在本机，不包含在 OPML 导出中。

一次同步先保存 RSS，再尝试下载最多 10 篇网页正文，全文阶段最多约两分钟；剩余任务会提示再次同步继续，即使订阅没有更新也能继续处理。失败项目需手动重试。已成功保存的网页正文不会每次同步重复下载或覆盖。

网页正文提取目前支持公开、无需登录、直接返回 UTF-8 / ASCII HTML 的文章；不执行网页脚本，不支持登录、付费墙、旧编码网页或多页拼接。部分网站无法提取，或只能提取到部分内容，请按原网站内容核对。过大的网页、复杂结构和正文会停止提取，仍保留 RSS 原文。

## 文章翻译

v0.0.4 beta 已包含翻译功能，正式版 v0.0.3 尚不支持。翻译用于英文文章翻成简体中文；首次翻译需要联网，文章内容会提交给所配置的服务，并按服务账户计费。默认使用阿里云百炼 Qwen-MT，也可配置 SiliconFlow、智谱或其他 OpenAI 兼容服务。

### 长按选词和选区翻译

长按正文约 0.6 秒选中单词，继续拖动可以扩选；松手后也可拖动两端的选区标记调整范围。扩选时手指可以落在行间或页边，终点会贴近最近的文字行；选区两端的标记可继续拖动调整。短划仍用于翻页。浮动工具条跟随选区，优先显示在上方，空间不足时显示在下方，只保留 **翻译** 按钮。点正文空白或按返回可关闭选区，不改变阅读位置。

点 **翻译** 才会把选中的英文文字发送给当前配置的翻译服务，沿用下方配置的 API Key。选区译文会缓存在本机；再次选择相同范围可直接查看，不重复请求。译文较长时，在小面板中点 **上一页 / 下一页** 查看完整内容；关闭面板继续阅读。网络失败、取消后可以手动重试，不自动重复请求。同步、正文下载和翻译共用一个后台任务，有其他任务进行时需等待完成。

RSS 内容、网页正文以及原文 / 译文 / 双语分别保留各自的选区译文；正文更新后旧范围不会套到新内容。当前支持本页拖选，暂不支持拖动跨页选区。

### 配置翻译服务

退出阅读器，连接电脑，在 Kindle 磁盘的 `native-rss/data/` 中新建纯文本文件 **translation.conf**（不要保存为 `.txt`）。使用 UTF-8 编码，值两边不加引号，也不加 `export`；以 `#` 开头的行是注释。下面是使用 SiliconFlow 的最简示例：

```ini
RSS_TRANSLATION_PROVIDER=siliconflow
RSS_TRANSLATION_API_KEY=在这里填写自己的APIKey
```

服务商、默认地址和默认模型如下。API Key 均需自行申请；服务的可用性、限流、收费规则和翻译效果由服务商决定，免费额度不保证长期可用，也不保证效果超过 Qwen。

| `RSS_TRANSLATION_PROVIDER` | 默认 endpoint | 默认 model | API Key 申请入口 |
| --- | --- | --- | --- |
| `qwen`（默认） | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` | `qwen-mt-flash` | [阿里云百炼密钥管理（北京）](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key) |
| `siliconflow` | `https://api.siliconflow.cn/v1/chat/completions` | `tencent/Hunyuan-MT-7B` | [硅基流动 API 密钥](https://cloud.siliconflow.cn/account/ak) |
| `zhipu` | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-4-flash-250414` | [智谱 API Keys](https://bigmodel.cn/usercenter/proj-mgmt/apikeys) |

登录对应平台后，在密钥页面创建 API Key，填入 `RSS_TRANSLATION_API_KEY`。智谱请选择“模型标准 API”类型的 Key，个人或团队套餐的 Key 不通用；参见[智谱官方指引](https://docs.bigmodel.cn/cn/guide/start/quick-start)。Qwen 的申请步骤见[百炼官方指引](https://help.aliyun.com/zh/model-studio/get-api-key/)，硅基流动见[官方指引](https://docs.siliconflow.cn/docs/usercases/use-siliconcloud-in-dify)。这里的 API Key 是调用凭证，token 是用量单位。

所有服务商统一使用 `RSS_TRANSLATION_API_KEY`，不再按模型或服务商区分 Key 变量名。切换服务商时同时填写对应平台的 Key；模型和地址不填时使用该服务商默认值，已填写的覆盖项也需要同步修改或删除。Qwen 服务仅支持 `qwen-mt-` 系列模型，Key 与地址的地域须一致；普通聊天模型请选择对应服务商或 `openai-compatible`。

如需覆盖模型或地址，可在文件中增加 `RSS_TRANSLATION_MODEL` 或 `RSS_TRANSLATION_ENDPOINT`。`openai-compatible` 是接口格式，Key 需向实际使用的服务商申请。例如，OpenAI 兼容服务必须明确提供完整的 `chat/completions` 地址和模型名：

```ini
RSS_TRANSLATION_PROVIDER=openai-compatible
RSS_TRANSLATION_API_KEY=在这里填写自己的APIKey
RSS_TRANSLATION_ENDPOINT=https://api.example.com/v1/chat/completions
RSS_TRANSLATION_MODEL=your-model-name
```

Endpoint 必须是完整请求地址，不是服务根地址；仅接受 HTTPS，字面回环地址上的 HTTP 仅用于本机测试。请求不跟随重定向、不继承代理。只填写可信地址，因为 API Key 和文章内容会发送给该服务。

开发时也可以设置同名 `RSS_TRANSLATION_*` 环境变量，环境变量优先于文件；空值也会覆盖文件值，空 API Key 会禁用请求。每次翻译任务开始时重新读取全部配置。旧版 Qwen 专用配置需将 Key 和地址变量名分别改为 `RSS_TRANSLATION_API_KEY`、`RSS_TRANSLATION_ENDPOINT`，值保持不变，并删除旧变量行；解析器会拒绝未知变量。若还保存了模型覆盖项，也统一改用 `RSS_TRANSLATION_MODEL`。

配置文件与 `--db` 指定的数据库放在同一个目录，不执行其中的 shell 命令。Key 保存在本地配置文件中，不写入 SQLite，也不包含在 OPML 或应用安装包中；完整备份整个应用文件夹时会一起复制，请妥善保管。切换服务不会自动重新翻译或清空已有缓存；继续未完成的文章翻译时，已有段落缓存可能来自之前的服务。

### 原文、译文和双语阅读

打开文章，点正文中间唤出工具栏，进入 **翻译 → 翻译为中文**。翻译的是当前选中的 RSS 内容或网页正文；RSS 只有摘要时，只会翻译摘要。想翻译全文，先下载并切换到网页正文。

翻译面板顶部显示阅读模式和当前内容来源，下方集中显示进度与操作。翻译中可以点 **暂停翻译**，或收起面板继续阅读；暂停后点 **继续翻译** 会复用已保存段落。完成后点 **继续阅读** 关闭面板。同步或其他文章翻译期间，本篇的翻译按钮会等待当前任务结束。

翻译在后台执行，完成后不会突然替换正在阅读的页面。普通段落会整段翻译，不在链接或粗体处断句。原文保留链接，中文译文按自然语序显示；代码和图片由应用保护。旧版碎片译文会提示需重新翻译，新译文完整保存后才清理旧缓存。双语新版排版使用较小的英文原段和正常字号、正常字重的中文译文，以留白分组，取消译文竖线和缩进。在面板选择 **原文 / 译文 / 双语**：原文显示英文，译文显示中文，双语在英文段落下面显示对应中文。图片和代码保持原样。切换时定位到当前段落附近，页码会随排版变化；退出重开会记住所选模式和该模式的阅读位置。

每个成功段落都会保存到本地，之后切换模式和离线阅读不再请求翻译。取消或失败后，点 **继续翻译剩余段落**，已保存段落会复用；缺少译文的段落保留英文并标明尚未翻译。每轮最多工作约五分钟，超时暂停后可继续。同步与翻译共用一个后台任务，同步期间需等待完成后再翻译。

遇到鉴权失败，请检查密钥、服务地址和模型权限；遇到限流、余额不足、断网或不完整响应，请处理后手动重试。请求不会自动重试或自动切换模型、服务商；取消不能撤回已经发到服务端的请求，因此可能仍有计费。原文更新后会提示重新翻译，旧译文不自动套到新正文上。原文、收藏及原有书签会保留。

## 打开文章和调整字号

点文章标题进入阅读，在正文区域左滑进入下一页、右滑返回上一页；也可以点正文左侧四分之一返回上一页，点右侧四分之一进入下一页。正常阅读时，点左上角圆形返回图标回到文章列表。下次再打开同一篇文章，会继续上次的位置。

滑动翻页适用于新版和原排版，需先收起阅读工具和面板；竖向拖动、多指触摸及顶部、底部按钮区域的拖动不会翻页，也不会触发抬手位置的按钮。到达文章首页或末页后，继续滑动停留在当前页，不自动切换文章。

顶部 Wi-Fi、电量的字号和顶部距离统一以首页为准；时间位置保持原样：首页左侧、二级页面居中、阅读页底部左侧。返回按钮仍在原来的左上角。阅读时，底部中间显示页码，右侧显示当前文章顺序（如「第 2 / 10 篇」）；到最后一页时，右侧篇数旁出现箭头，点击即可完成阅读并进入列表中的下一篇。设备状态约每 30 秒检查一次。

阅读时，点一下正文中间，会出现底部工具栏。点正文可直接收起全部工具；左上角返回图标先收起面板，再收起工具栏，最后返回文章列表：

- **排版**：切换「新版排版 / 原排版」，以及调整字号、行距和页边距。半屏面板显示当前值，选中的预设以黑底显示；设置自动保存。新版排版保留标题层级、引用、代码和图文结构。
- **正文**：下载网页正文、查看下载及图片缓存状态，并切换 RSS 原文 / 网页正文。
- **翻译**（beta）：英译中、继续翻译，并切换原文 / 译文 / 双语。
- **图片**：打开图片面板，用 **上一张 / 下一张** 选择图片，再点 **放大**。看完点 **收起**，继续阅读。
- **信息**：查看文章标题、作者、日期和原文地址。

v0.0.3 已把新版排版接进原来的 RSS 入口，不需要另开阅读器。新文章默认使用新版；明确选过原排版时会保留选择。升级前已保存原版进度的文章会先沿用原排版，避免跳回开头；可以在排版面板主动切换。两种排版分别记住位置，切换不保证落在同一段。

新版遇到过大的文章或无法解析的内容，会提示并回到原排版；已保存的进度仍保留。正文或图片资源变化后，新版书签可能从首页开始。查看大图继续使用图片面板。

喜欢的文章先点正文中间唤出工具栏，再点右上角星标收藏，再点一次取消收藏。面板覆盖正文，开合不会重新分页或改变阅读位置。

## 找到想看的文章

文章列表底部左侧是 **菜单**，中间是页码和文章数量，右侧并排放 **上页 / 下页**；到第一页或最后一页时，对应按钮会置灰。菜单向上展开，点击菜单外部可收起。

文章列表可以切换“未读”“全部”“收藏”。刚下载的文章通常先看“未读”；想找以前读过的文章时，切换到“全部”。

点击列表上方的范围标题（如 **全部订阅** 或分组名）及其箭头，可以选择只看某个分组。选中一个大分组时，其中的子分组也会一起显示。

搜索用来查找已经保存在 Kindle 上的文章标题。搜索、订阅编辑和分组选择都使用左上角圆形返回图标；输入页返回会放弃这次输入，已确认内容不变。中文输入时，先输入拼音，再点候选字词。例如输入 `keji`，再选择“科技”；拼音里的 ü 用 `v` 代替。想输入网址时切换到英文键盘。

## 发现订阅源（未发布）

以下为开发中的新功能，已发布的 beta.2 和正式版暂不包含。

进入 **菜单 → 订阅 → 发现订阅**，连接 Wi-Fi 后点右上角 **刷新**。下载的是可供挑选的来源列表，不会一次性订阅所有网站。缓存后可以离线按名称、主题或网址查找；**主题**采用源库本身的分组，没有分类的来源显示为“未分类”。

点来源旁的 **订阅**，在原有添加页面确认名称、RSS 地址和所属分组，再点右上角 **保存**。来源列表会标记已经订阅的地址；文章仍通过原有同步功能下载。源库的收录不代表每个 RSS 地址都仍然有效或提供全文。

从订阅管理首页点 **订阅源库** 管理来源；发现页也可点击当前源库范围切换 OPML 列表：

- **中文独立博客**和 **Awesome RSSHub Routes** 提供可在应用内查找的 OPML 列表。点 **查看** 可核对 OPML 原始地址，再点 **查看订阅源** 单独查找；范围选择页也可合并查找已缓存的列表。
- 源库页右上角 **添加**只需填写名称和 OPML 文件地址。地址必须是以 **`.opml`** 结尾的 HTTP(S) URL（后缀大小写不限），不能带查询参数或 `#` 片段；普通网页、单个 RSS 地址和没有该后缀的接口不能保存。下载时仍会检查内容确实为 OPML。自定义源库可编辑和移除，表单右上角保存；左上角返回不会保存草稿。
- 内置仅保留上述两个 OPML 源库。旧版用户自定义网站记录仍可读取和移除；若编辑保存，须改为符合上述要求的 OPML 文件地址。

源库下载在后台执行，可在发现页取消；与文章同步、翻译和在线升级共用一个后台任务，需要等待当前任务完成。失败、无效响应或取消时保留之前成功保存的缓存。移除源库不影响已经添加的订阅、文章和阅读状态。

自定义源库最多 100 个，单个源库最多 5000 个来源、下载上限 8 MiB。合并查找最多加载 10000 个来源，超出时需选择单个源库查找。源库及缓存保存在阅读数据库中，完整备份数据库时会一并保留；普通订阅 OPML 导出仍只包含自己的订阅和分组。

## 整理订阅和分组

点左下角 **菜单 → 订阅**，可以看到已经添加的网站。

- 点网站名称，查看这个网站的文章。
- 点右侧 **编辑**，修改名称、订阅地址或所属分组，再点 **保存更改**。
- 点底部 **管理分组**，新增、重命名、移动或删除分组。
- 想在一个分组里再建一层，点 **子分组**；想改变它放在哪里，编辑时选择 **上级分组**。

删除分组后，原来的订阅会放到“未分组”，文章和收藏会保留。

**取消订阅前，先收藏还想保留的文章。取消订阅后，只有这个网站的收藏文章会留下。**

## 从其他阅读器批量导入

如果已经在其他阅读器里订阅了很多网站，可以先在那里导出 **OPML**。这是一种保存订阅列表的文件，通常以 `.opml` 结尾，不需要自己编辑文件内容。

1. 在本阅读器中退出应用，再连接电脑。
2. 把导出的文件改名为 `feeds.opml`。
3. 打开 Kindle 磁盘里的 `native-rss` 文件夹，再打开里面的 `data` 文件夹。如果没有 `data`，手动新建一个同名文件夹。
4. 把 `feeds.opml` 复制进去，安全弹出 Kindle。
5. 打开阅读器，点左下角 **菜单 → 订阅 → 底部 OPML → 导入 OPML**，再确认导入。
6. 返回文章列表，连上 Wi-Fi 后同步，就会开始下载文章。

导入会把列表合并进现有订阅，相同地址不会重复添加。

## 导出订阅和备份阅读记录

只想把订阅列表带到另一个阅读器时：

1. 点左下角 **菜单 → 订阅 → OPML → 导出 OPML**。
2. 退出应用并连接电脑。
3. 在 `native-rss` → `data` 中找到 `subscriptions.opml`，复制到电脑。

这个文件只保存订阅和分组，**不保存收藏、阅读位置或下载好的文章**。

想完整备份时，先退出应用，再把 Kindle 上整个 `native-rss` 文件夹复制到电脑。beta 的文章及选区译文也会随数据库备份；`data/translation.conf` 中的 API Key 和 `.update` 中的升级回滚数据会一起复制，请妥善保管，不要公开上传。

## 清理不再需要的文章

想腾出空间时，点左下角 **菜单 → 同步**，在同步弹窗中点 **缓存管理**。这里可以清理较早读完的文章，页面会说明要删除哪些内容，确认后再清理。

清理会删除选中文章的下载内容和阅读记录；收藏、未读和正在阅读的文章会保留。网站仍提供的文章，下次同步时可能再次出现。

## 设置与在线升级

beta 可通过 **菜单 → 设置 → 在线升级** 手动检查 GitHub 后续 beta 与正式版本、下载并校验后安装重启。正式版 v0.0.3 转入 beta 需 USB 安装，不会自动切换通道；空间、首页适配和恢复限制见[在线升级说明](INSTALL.md#在线升级)。验证 beta.1 → beta.2 的步骤见[在线升级测试](INSTALL.md#在线升级测试)。程序升级与订阅自动同步是两个独立功能，不会后台静默安装新版。

左下角 **菜单 → 设置** 的“关于与许可”中可查看分发许可、源码位置及完整条款的位置。

同一设置页还可开关自动同步，以及“在 Kindle 首页显示 RSS订阅”。首页显示默认关闭，需要另行安装匹配固件的[首页适配](HOME.md)；只打开开关不会自动安装适配，也不会在系统首页下载新文章。

## 正确退出

回到文章列表，点左下角 **菜单 → 退出**，再确认退出。

连接电脑传文件、升级、备份或卸载之前，都先退出阅读器。Kindle 休眠后阅读器也会退出，下次重新打开即可继续使用。
