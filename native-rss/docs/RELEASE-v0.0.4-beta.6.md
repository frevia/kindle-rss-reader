# RSS Reader v0.0.4-beta.6

修复 Kindle 书库入口在在线安装后自动重启失败的问题，改进在线升级页，让用户主动发起的翻译优先于自动同步，并内置受支持固件的首页 RSS 适配。

## 在线安装与恢复

从书库打开阅读器时，在线安装后的旧启动器曾先请求 Kindle 首页。系统因此卸载 SH_Integration，并在新版启动前终止启动脚本。下次打开阅读器时会恢复旧程序和阅读数据库。beta.6 在安装成功后恢复系统服务、释放会话锁并直接启动新版。安装失败时仍会返回 Kindle 首页。新版首次成功显示界面后确认升级。

旧 beta 可正常退出、备份整个 `native-rss`，再[通过 USB 合并安装](INSTALL.md#通过-usb-升级)，保留 `native-rss/data`。在线升级仍由设备上当前运行的启动器交接。开发验证前须先[替换 beta.6 启动器](INSTALL.md#旧版升级前修复启动器)并重新打开旧版。

## 升级页与翻译

- 在线升级页并排显示当前和目标版本，集中显示状态与安装条件。长发布说明可翻页。检查更新可与订阅同步并行，下载和安装仍需等待后台任务退出。
- 发起选区或整篇翻译时，如正在自动同步，阅读器先取消该轮同步，等它退出后再翻译。等待期间可以取消翻译。手动同步与其他读写任务仍沿用原有互斥规则。

## 首页 RSS

普通安装包内置 KPW3／5.16.2.1.1 的差分配方，首次开启仍需原始首页文件通过 SHA-256 校验。打开 **设置 → 首页 RSS**，正常退出阅读器后，设备会生成适配副本并重载首页。其他机型或固件的开关显示为灰色。

重载时等待 Kindle 首页接口注册完成，再请求返回首页。KPW3 已从空数据库复测首次开启，RSS 书架成功显示，系统应用错误弹窗未再出现。适配默认关闭。完整停用仍可从 KUAL 操作，见[首页 RSS 指南](HOME.md)。

## 验证范围

KPW3 系统日志确认书库入口卸载并终止了升级启动器，回滚后的阅读数据库与升级前快照一致。已在同一设备的 BusyBox 上隔离验证新旧重启交接及安装失败路径，并通过宿主启动器、升级与打包测试。完整在线安装、其他机型及断电恢复需分别验证。
