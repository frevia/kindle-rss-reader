# RSS Reader v0.0.4-beta.4

> **已确认的在线安装问题（2026-11-05）**：完整 beta.3 → beta.4 验证发现，安装进度页可能在字体文件被替换后触发 SIGBUS 并回滚。本版附件尚未包含字体生命周期修复，旧版当前推荐正常退出后 USB 安装完整 [beta.5](RELEASE-v0.0.4-beta.5.md)；下方仅修锁的在线步骤暂不适用。原附件保持不变。

修复在线升级安装成功后仍回滚的问题，保留 beta.3 的订阅源发现、订阅管理导航、升级进度反馈以及此前的阅读与翻译功能。[下载 beta.4](https://github.com/frevia/kindle-rss-reader/releases/tag/v0.0.4-beta.4)。历史 beta.3 附件保持不变，正式版仍为 v0.0.3。

## 本版修复

Kindle 的 BusyBox `timeout` 命令结束后，短暂残留的监控进程可能仍持有继承的会话锁。安装与系统恢复虽然成功，新启动器却无法获取锁，提示“阅读器已经运行”；下次打开时触发“上次升级未完成”的回滚。

本版在安装成功、系统恢复完成后，先显式释放会话锁再重启。解锁失败时停止重启，保留原有数据库备份、文件校验和回滚保护。无数据库结构或升级归档协议变化。

## beta.1／beta.2／beta.3 用户怎么升级

**当前推荐通过 USB 安装完整 [beta.5 包](RELEASE-v0.0.4-beta.5.md)。** 正常退出阅读器，备份整个 `native-rss`，按[安装教程](INSTALL.md#通过-usb-升级)合并复制三个文件夹，保留 `native-rss/data` 与其他应用文件。

旧启动器本身有上述问题，**只下载新安装包不会修复正在运行的旧启动器**。下方旧版启动器说明仅修复会话锁；在线验证还需额外的字体生命周期修复，当前公开附件不足以完成此验证。仅看到版本号 beta.3 不能确认启动器已修复。

升级前连接 Wi-Fi、停用已启用的首页 RSS，并保留至少 400 MB 空间；安装期间保持唤醒，不要连接 USB、按电源键或关机。GitHub 下载超时可稍后重试或使用 USB 安装，不要绕过校验。完成后核对版本、订阅、收藏、阅读位置和翻译配置，再正常退出重开，确认没有回滚提示。

已经回滚的设备先确认原版可打开并导出诊断，保留 `.update` 中的备份。不要删除数据库、SQLite 日志或升级 journal 来强制跳过恢复。

## 验证范围

- KPW3／5.16.2.1.1 已复现安装成功后自动重启被会话锁阻挡；真机最小复现确认锁由 timeout 监控进程继承，显式解锁后可重新获取。
- 修复前后使用同一 beta.3 包对照，修复后通过锁交接；期间另遇系统进程状态检查失败，设备重新唤醒后完成待确认安装。beta.3 正常退出重开通过，阅读数据库与升级前逐字节一致。这些证据对应热修复，不能替代完整 beta.4 包的在线升级验收。
- 新增真实文件锁继承与解锁失败回归测试；宿主构建、CTest、ARM 静态构建与发布归档校验结果以本版构建记录为准。

其他 Kindle 机型、真实断电恢复、反复休眠和长期使用仍待验收。机型范围及反馈方式见[兼容说明](COMPATIBILITY.md)；原生首页适配仍仅限已核对文件哈希的 KPW3／5.16.2.1.1。

已在上述 KPW3 上补齐两项启动器修复后，从 GitHub 实际检查、下载并校验原始 beta.4 安装包，完成备份、安装、自动重启和正常退出重开。9 张数据表内容与升级前基线一致，订阅和翻译配置文件一致，自动同步已恢复；7 项针对性回归测试通过。安装后也再次补入字体修复，保护后续升级。该结果仅适用于热修复后的客户端，不代表原始 beta.4 附件已包含字体修复。
