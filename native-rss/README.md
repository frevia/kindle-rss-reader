# RSS Reader 文档

想把阅读器装到 Kindle 上，从这里开始：

1. [安装教程](docs/INSTALL.md)：下载最新版、复制文件、打开阅读器，以及升级或卸载。
2. [使用指南](docs/USAGE.md)：添加订阅、下载文章、阅读、分组和备份；源码开发版的自动同步、文章与选区翻译也在这里。

文档以当前源码为准；标为“源码开发版”的新增功能尚未进入已发布的 v0.0.3 安装包，见[未发布更新记录](../CHANGELOG.md#未发布)。[在线升级](docs/INSTALL.md#在线升级源码开发版)首次启用仍需 USB 安装；新兼容包的设备条件与实测范围见[机型兼容说明](docs/COMPATIBILITY.md)。

原生首页的可选 RSS 卡片见[首页适配说明](docs/HOME.md)，普通安装默认关闭。

其他机型试装请按[测试安装流程](docs/COMPATIBILITY.md#测试安装流程)操作，成功或失败均可使用[兼容反馈模板](docs/COMPATIBILITY.md#怎么反馈兼容情况)提交机型、固件、分项结果与脱敏报告。

入口没出现或应用打不开时，再看[启动问题排查](docs/TROUBLESHOOTING.md)。

也可以先回到[项目首页](https://github.com/frevia/kindle-rss-reader)了解功能。

如果你想修改代码或自己编译，请看[开发参考](docs/DEVELOPMENT.md)和[贡献指南](https://github.com/frevia/kindle-rss-reader/blob/main/CONTRIBUTING.md)。这些不是安装阅读器的必做步骤。
